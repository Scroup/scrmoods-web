# Общий бюджет: как завести свой сервер

Чтобы вести План и Расходы вдвоём на разных телефонах, приложению нужен маленький сервер. Он бесплатный: Cloudflare Worker и хранилище KV. Заводится один раз, примерно за 10 минут. Компьютер с программами не нужен, всё делается в браузере.

Сервер хранит только шифр. Ключ шифрования — это код синхронизации, и он есть только на ваших устройствах. Даже владелец сервера (то есть вы) не прочитает там бюджет без кода.

## 1. Аккаунт
Зарегистрируйтесь на https://dash.cloudflare.com/sign-up. Хватит бесплатного тарифа, карта не нужна.

## 2. Хранилище KV
1. В меню слева: **Storage & Databases → Workers KV** (в некоторых версиях панели — **Workers & Pages → KV**).
2. **Create instance** (или **Create a namespace**), имя — `scrmoney-sync`, затем **Create**.

## 3. Worker
1. **Workers & Pages → Create application → Start with Hello World! → Get started**.
2. Имя — `scrmoney-sync`, затем **Deploy**.
3. **Edit code**: удалите всё, что там есть, вставьте содержимое файла `sync-worker.js` из этой папки и нажмите **Deploy**.

## 4. Привязать хранилище к Worker'у
1. Откройте Worker `scrmoney-sync` → вкладка **Bindings** (или **Settings → Bindings**) → **Add binding**.
2. **KV namespace** → **Add binding**.
3. Variable name: **`SYNC`** (именно так, большими буквами). Хранилище — `scrmoney-sync`.
4. **Add binding** / **Deploy**.

## 5. Проверить
Откройте адрес Worker'а — он показан на его странице, вида `https://scrmoney-sync.ВАШЕ-ИМЯ.workers.dev`. Должно быть:
```
{"ok":true,"app":"scrmoney-sync","kv":true}
```
Если там `"kv":false`, значит хранилище не привязано или переменная названа не `SYNC` (шаг 4).

## 6. В приложении
1. scrmoney → **Настройки → Общий бюджет** → впишите адрес Worker'а → **Создать общий бюджет**.
2. **Пригласить: отправить ссылку** → отправьте ссылку партнёру. Он откроет её у себя и окажется в том же бюджете.
   Можно и вручную: «Подключиться по коду», вписать адрес сервера и код из 20 знаков.
3. Справа в шапке появится облачко: зелёное — всё синхронизировано, мигает — идёт синхронизация, красное — ошибка (подробности — в Настройках).

Чтобы не вписывать адрес на каждом устройстве, его можно один раз записать в `index.html`: константа `SYNC_SERVER` (поиск по `const SYNC_SERVER`). Тогда поле адреса в Настройках пропадёт.

## Как это работает
- **Общее:** План целиком (счета, доходы, обязательные, цели, лимиты, столбец «Факт»), вписанные суммы за месяц, Расходы и свои категории расходов.
- **Не общее:** вкладка «Приходы» (доллары/евро для налогов), стиль, цвета, ставка налога. В общий план уходят только суммы «Приходов» по месяцам в лари, чтобы «Факт» и средний доход были одинаковыми у обоих.
- Синхронизация идёт сама: при открытии, через пару секунд после каждой правки, при возврате в приложение и раз в 45 секунд, пока оно открыто. Правки без интернета уйдут, когда появится связь.
- Если вы оба поменяли разное (один — лимит на продукты, другой — добавил расход), сохранится и то и другое. Если одно и то же поле — остаётся более поздняя правка.
- Пока открыто окно, анкета или курсор стоит в поле ввода, чужие правки ждут, чтобы ничего не менялось под рукой.

## Лимиты бесплатного тарифа
У KV на бесплатном тарифе 100 000 чтений и 1 000 записей в сутки. Запись бывает только после правки (не чаще раза в несколько секунд), так что двоим этого хватает с большим запасом.

## Безопасность
- Код синхронизации — это и ключ. Не публикуйте его. Если код утёк: «Отключить на этом устройстве» на всех устройствах, затем на одном «Создать общий бюджет» (появится новый код) и пригласите партнёра заново.
- Шифрование — AES-GCM 256, ключ получается из кода через PBKDF2 (150 000 итераций). Адрес записи на сервере — это хэш кода, а не сам код.
- Worker принимает запросы только со страницы https://scroup.github.io (и с localhost для проверки). Если приложение переедет на другой адрес, поправьте `ORIGINS` в `sync-worker.js`.
