# Общий бюджет: как завести свой сервер

## Уже завели сервер раньше? Обновите его код (версия 2, с историей)
Откройте Worker `scrmoney-sync` → **Edit code** → удалите всё → вставьте новое содержимое `sync-worker.js` → **Deploy**. Хранилище и привязка остаются как были. Проверка: адрес Worker'а должен показывать `"version":2`. Без обновления синхронизация работает, но «Версии на сервере» не будет.

---

Чтобы вести План, Расходы и Приходы вдвоём на разных телефонах, приложению нужен маленький сервер. Он бесплатный: Cloudflare Worker и хранилище KV. Заводится один раз, примерно за 10 минут. Компьютер с программами не нужен, всё делается в браузере.

Сервер хранит только шифр. Ключ шифрования — это код синхронизации, и он есть только на ваших устройствах. Даже владелец сервера (то есть вы) не прочитает там бюджет без кода.

## 1. Аккаунт
Зарегистрируйтесь на https://dash.cloudflare.com/sign-up. Хватит бесплатного тарифа, карта не нужна.

## 2. Хранилище KV
1. В меню слева: **Storage & Databases → Workers KV** (в некоторых версиях панели — **Workers & Pages → KV**).
2. **Create instance** (или **Create a namespace**), имя — `scrmoney-sync`, затем **Create**.

## 3. Worker
1. **Workers & Pages → Create application → Start with Hello World! → Get started**.
2. Имя — `scrmoney-sync`, затем **Deploy**.
3. **Edit code**: удалите всё, что там есть, вставьте содержимое файла `sync-worker.js` из этой папки и нажмите **Deploy**.

## 4. Привязать хранилище к Worker'у
1. Откройте Worker `scrmoney-sync` → вкладка **Bindings** (или **Settings → Bindings**) → **Add binding**.
2. **KV namespace** → **Add binding**.
3. Variable name: **`SYNC`** (именно так, большими буквами). Хранилище — `scrmoney-sync`.
4. **Add binding** / **Deploy**.

## 5. Проверить
Откройте адрес Worker'а — он показан на его странице, вида `https://scrmoney-sync.ВАШЕ-ИМЯ.workers.dev`. Должно быть:
```
{"ok":true,"app":"scrmoney-sync","kv":true}
```
Если там `"kv":false`, значит хранилище не привязано или переменная названа не `SYNC` (шаг 4).

## 6. В приложении
1. scrmoney → **Настройки → Общий бюджет** → впишите адрес Worker'а и своё имя → **Создать общий бюджет**.
2. **Пригласить: отправить ссылку** → отправьте ссылку партнёру. Он откроет её у себя, впишет имя (или выберет себя, если это ваше второе устройство) и окажется в том же бюджете.
   Можно и вручную: «Подключиться по коду», вписать адрес сервера и код из 20 знаков.
3. Справа в шапке появится облачко: зелёное — всё синхронизировано, мигает — идёт синхронизация, красное — ошибка (подробности — в Настройках).

Чтобы не вписывать адрес на каждом устройстве, его можно один раз записать в `index.html`: константа `SYNC_SERVER` (поиск по `const SYNC_SERVER`). Тогда поле адреса в Настройках пропадёт.

## Как это работает
- **Общее:** План целиком, Расходы со своими категориями и **Приходы**. У каждого прихода есть владелец: на вкладках «Приходы» и «Год» переключатель «Мои / имя партнёра / Все», налог и лимит малого бизнеса каждый видит по своим. В плане учитываются приходы всех.
- **Не общее:** стиль, цвета, ставка налога.
- Синхронизация идёт сама: при открытии, через пару секунд после правки, при возврате в приложение и раз в 45 секунд, пока оно открыто. Правки без интернета уйдут, когда появится связь.
- **Побеждает самая свежая правка.** У каждого поля (расход, приход, строка плана, сумма, лимит) запоминается время, когда его изменил человек. Если вы оба поменяли разное, сохранится и то и другое; если одно и то же — более поздняя правка.
- **Записи не пропадают сами.** Запись исчезает только после того, как её явно удалили. Если какое-то устройство или старая вкладка покажет старую копию без новых записей, это не считается удалением: записи вернутся.
- Вкладки на одном устройстве видят правки друг друга сразу, синхронизирует одна вкладка за раз. Старая версия приложения (например, из кэша) не может ни прочитать, ни перезаписать данные нового формата.
- Пока открыто окно, анкета или курсор стоит в поле ввода, чужие правки ждут, чтобы ничего не менялось под рукой.

## Резервные копии
**Настройки → Резервные копии.**
- Приложение само делает копию раз в день и перед каждым удалением, пришедшим с другого устройства (хранятся 12 последних).
- **Версии на сервере** — Worker сохраняет прежнюю версию не чаще раза в 10 минут и хранит 30 дней (нужен Worker версии 2).
- Любую копию можно вернуть — она уйдёт всем участникам. Текущие данные перед этим тоже сохраняются в копию.
- **Сохранить всё в файл** — копия в .json, которую можно загрузить обратно кнопкой «Загрузить из файла».

## Лимиты бесплатного тарифа
У KV на бесплатном тарифе 100 000 чтений и 1 000 записей в сутки. Запись бывает только после правки (не чаще раза в несколько секунд) плюс копия в историю не чаще раза в 10 минут, так что двоим этого хватает с большим запасом.

## Безопасность
- Код синхронизации — это и ключ. Не публикуйте его. Если код утёк: «Отключить на этом устройстве» на всех устройствах, затем на одном «Создать общий бюджет» (появится новый код) и пригласите партнёра заново.
- Шифрование — AES-GCM 256, ключ получается из кода через PBKDF2 (150 000 итераций; формат 2 — с другой «солью», чем у прежней версии). Адрес записи на сервере — это хэш кода, а не сам код.
- Worker принимает запросы только со страницы https://scroup.github.io (и с localhost для проверки). Если приложение переедет на другой адрес, поправьте `ORIGINS` в `sync-worker.js`.
