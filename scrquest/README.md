# scrquest

Игра на неделю: дела, привычки и квесты дают баллы (Б), баллы копятся и меняются на награды. Приложение сделано по шаблону геймификации Бины Кварц v1.3 ([@kvarrts](https://t.me/kvarrts)). Оформление, четыре стиля и синхронизация между устройствами такие же, как в scrmoney.

- **Неделя**: дни с понедельника по воскресенье. Кнопка «Записать дело»: день, категория, что сделано и баллы. Подсказки подставляют категорию и баллы из прошлых записей и «Повторов». Галочки привычек ставятся в днях. Сюжетные и побочные квесты: условие победы, баллы, статус (не начат / в процессе / ✅ готов) и чек-лист. Баллы за квест начисляются только со статусом «✅ готов». Внизу итоги недели: категории, обычные дела, привычки, сюжетные, побочные, серии 7/7 и «Б за неделю». Незавершённые квесты прошлой недели можно перенести одной кнопкой. На телефоне дни переключаются полоской сверху, на широком компьютере (от 1200 px) видна вся неделя, как в таблице.
- **Привычки**: баллы за день и бонус за 7 дней из 7. Галочка запоминает баллы на момент отметки, поэтому изменение баллов не меняет прошлые недели. Убранная привычка остаётся в прошлых неделях.
- **Повторы**: разделы (Тело, Быт…) с отдельными делами и делами по частоте: каждый день, раз в неделю, раз в 2 недели, раз в месяц. У каждого дела чек-лист и баллы. Кнопка ✓ записывает дело в сегодняшний день, по ней же видно «сделано 3 дня назад · пора снова». Дело с чек-листом можно взять квестом на неделю.
- **Побочки**: подбор по тегам (остаются побочки со всеми выбранными тегами) и банк идей с часами, деньгами, условиями и статусом (доступно / неделя / сделано / архив). «В неделю» создаёт побочный квест. Когда квест «✅ готов», в банке он отмечается как сделанный.
- **Награды**: копилка (заработано, потрачено, в копилке), «сейчас коплю на», магазин наград с ценой в рублях для ориентира и стоимостью в баллах, начисления по неделям и вручную, история покупок. Покупку можно отменить, тогда баллы вернутся. Баллы недели попадают в копилку сразу, закрывать неделю не нужно.
- **Настройки**: категории, привычки, стиль (Классика, Бумага, Блокнот, Зелёное яблоко), цвета, синхронизация, резервные копии, «Как играть».

## Синхронизация между устройствами

**Настройки → Синхронизация → Включить синхронизацию**, затем «Добавить устройство: отправить ссылку» и открыть ссылку на другом устройстве. Можно и вручную: «Подключиться по коду» и ввести код из 20 знаков. Данные шифруются на устройстве кодом синхронизации (AES-GCM), сервер видит только шифр.

Сервер тот же, что у scrmoney (Cloudflare Worker из `../scrmoney/sync-worker.js`): заводить новый не нужно. Если scrmoney уже подключён на этом устройстве, адрес подставится сам. Подробнее — в `SYNC.md`.

Алгоритм такой же, как в scrmoney (формат 2): у каждой записи время последней правки, побеждает самая свежая, удаление — только явное, старая вкладка или старая копия ничего не сотрёт. Копии на устройстве делаются раз в день и перед удалениями с другого устройства, сервер хранит версии каждые 10 минут (30 дней).

## Где живёт

Папка `scrquest/` внутри репозитория scrmoods-web, публикуется тем же GitHub Pages: **https://scroup.github.io/scrmoods-web/scrquest/**. Шрифты Lora берутся из корня репозитория (`../lora_*.woff`). Данные хранятся отдельно от scrmoods и scrmoney (ключи `scrquest.*`).

На iPhone: открыть ссылку в Safari → «Поделиться» → «На экран Домой». Приложение с домашнего экрана хранит данные отдельно от Safari, поэтому синхронизацию в нём нужно подключить отдельно. При изменении файлов повышайте `VERSION` в `sw.js`.

## Файлы

- `index.html`: всё приложение (CSS стилей взят из scrmoney, чтобы оформление совпадало)
- `sw.js`: работа без сети, страница — network-first
- `manifest.webmanifest`, `*.png`: название и иконки
- `SYNC.md`: как подключить синхронизацию
