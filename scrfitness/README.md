# scrfitness

Тренировки из рилсов в Инстаграме. Оформление и темы такие же, как в scrmoods, scrmoney и scrcook.

- **Комплексы**: готовые тренировки с оценкой времени, кругами и отдыхом. Кнопка «Начать тренировку» открывает режим «делай за мной»: фигурка показывает движение, упражнения на время идут по таймеру, повторы отмечаются кнопкой «Сделал», на отдыхе видно следующее упражнение. За 3 секунды до конца подхода звучит сигнал, экран не гаснет.
- **Упражнения**: анимированная фигурка, техника по шагам, частые ошибки, варианты «проще» и «сложнее». Поиск и фильтры по мышцам, отдельный фильтр «Из рилсов».
- **История**: каждая завершённая тренировка с датой и длительностью, итоги за всё время и за 7 дней. Сохранение и загрузка истории в XML.
- **Настройки**: тема, звуковые сигналы.

## Где живёт

Папка `scrfitness/` внутри репозитория scrmoods-web, публикуется тем же GitHub Pages: **https://scroup.github.io/scrmoods-web/scrfitness/**. Шрифты Lora берутся из корня репозитория (`../lora_*.woff`). История хранится отдельно от других приложений.

На iPhone: открыть ссылку в Safari → «Поделиться» → «На экран Домой». История хранится на телефоне, поэтому время от времени нажимайте «Сохранить в XML» на вкладке «История». При изменении файлов повышайте `VERSION` в `sw.js`.

## Как добавить упражнение или комплекс

Всё лежит в `index.html`:

- `EX` — упражнения. Поля: `name`, `muscles` (теги для фильтров), `dose`, `cues` (шаги техники; первый показывается на отдыхе, второй во время подхода), `bad`, `easier`, `harder`, `src` (ключ из `SRC`, если упражнение из рилса), `timed` и `front` (фигурка анфас).
- `poses` — два положения фигурки по 11 точек `x,y` в поле 180×150 (пол на y=149): голова, шея, таз, колено и стопа дальней ноги, колено и стопа ближней, локоть и кисть дальней руки, локоть и кисть ближней. Фигурка плавно качается между ними за `period` секунд.
- `WORKOUTS` — комплексы: `items` — пары `[id упражнения, { reps } или { sec }]`, `rounds`, `rest` (между упражнениями), `roundRest` (между кругами), `src`.
- `SRC` — авторы рилсов и ссылки.

## Формат истории (XML)

```xml
<?xml version="1.0" encoding="UTF-8"?>
<trainingHistory version="1" exported="2026-10-13T08:00:00Z">
  <session workout="morning" date="2026-10-13T07:30:00Z" durationSec="642" rounds="2">
    <title>Зарядка на каждый день</title>
    <exercise id="jacks" seconds="40"/>
    <exercise id="squat" reps="15"/>
  </session>
</trainingHistory>
```

Обязательны только `workout` и `date`. При загрузке тренировки добавляются к текущим, совпадающие по комплексу и дате пропускаются.
