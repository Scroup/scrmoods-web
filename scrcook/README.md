# scrcook

Книга рецептов из рилсов в Инстаграме. Оформление и темы такие же, как в scrmoods и scrmoney.

- **Рецепты**: поиск по названию и продуктам, категории (супы, курица, паста, духовка…), сортировка по сложности. В рецепте — рисунок блюда, ингредиенты с отметками «уже положил» и шаги. У каждого продукта написано, где его купить в Тбилиси.
- **Таймер**: несколько таймеров сразу, с подписью («Картошка», «Духовка»), пауза и +1 минута. Быстрые кнопки от 1 минуты до часа, а в шагах рецептов — кнопки с временем из шага («Таймер 30 мин»). Идущий таймер виден в шапке на любой вкладке. Когда время вышло — экран-будильник, звук и уведомление (если разрешено). На iPhone страница засыпает при погасшем экране, поэтому пока идёт таймер, экран не гаснет (выключается в настройках); для заблокированного телефона надёжнее Siri.
- **Покупки**: кнопка «Добавить в покупки» в рецепте кладёт в список всё, что ещё не отмечено. Список сгруппирован по местам: рынок, супермаркет, Agrohub или Fresco, «дома или замена».
- **Магазины**: Дезертирский рынок, Навтлуги, сети и премиум-магазины — что из рецептов где искать.
- **Настройки**: тема, звук таймера, «не гасить экран», уведомления, сброс отметок.

## Где живёт

Папка `scrcook/` внутри репозитория scrmoods-web, публикуется тем же GitHub Pages: **https://scroup.github.io/scrmoods-web/scrcook/**. Шрифты Lora берутся из корня репозитория (`../lora_*.woff`). Отметки и список покупок хранятся отдельно от scrmoods и scrmoney.

На iPhone: открыть ссылку в Safari → «Поделиться» → «На экран Домой». При изменении файлов повышайте `VERSION` в `sw.js`.

## Как добавить рецепт

Рецепты лежат в `index.html` в массиве `RECIPES`. Поля ингредиента: `n` — название, `q` — сколько, `s` — пояснение, `o` — мера из оригинала, `w` — где купить, `alt: 1` — в Тбилиси не нашёлся. 

## Картинки блюд

Сейчас у рецептов нарисованные иллюстрации (массив `ART` в `index.html`). Чтобы поставить своё фото: положите файл в `img/` (лучше 16:10, около 1200×750), впишите его в `IMAGES` в `index.html` — например `pirog: 'img/pirog.jpg'` — и добавьте `'./img/pirog.jpg'` в `FILES` в `sw.js`, затем повысьте `VERSION`. Ключи: pirog, hashlama, kurica, sup, vinegret, pasta, kartsup, shnicel, cajun.

## Файлы

- `index.html`: всё приложение вместе с рецептами
- `sw.js`: работа без сети
- `manifest.webmanifest`, `*.png`: название и иконки
- `img/`: сюда класть свои фото блюд
- шрифт Lora — общий, в корне репозитория
